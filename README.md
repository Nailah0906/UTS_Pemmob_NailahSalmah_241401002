## Informasi Aplikasi
* **Nama Aplikasi:** NaiQ
* **Deskripsi Singkat:** Aplikasi kuis pilihan ganda bertema Hachiware yang memungkinkan pengguna memasukkan nama, menjawab 10 soal, dan melihat skor akhir.
* **Fitur-fitur:**
  * Input nama pemain sebelum memulai kuis.
  * 10 soal pilihan ganda dengan data dummy.
  * Navigasi Previous & Next antar soal.
  * Indikator progres bar soal.
  * Menyimpan state jawaban biar ga ilang.
  * Result skor.
  * Responsive design (lumayan rapi di HP dan Web Browser).
